# Moe Yu — Portfolio

Personal portfolio website of **Moe Yu**, a Computer Engineering graduate applying for Software Engineer, AI Engineer, and Data Analyst roles.

It's a single scrolling page covering:

- **About** — intro, work experience, and education (as a timeline)
- **Projects** — trading bot, image-processing app, mobile and web apps, with links to the code
- **Technologies** — languages, AI & data tools, and developer tools
- **Contact** — email, phone, location, and availability

Includes a light/dark mode switch and works on phones, tablets, and desktops.

## Built with

- [React 18](https://react.dev/) (Create React App)
- [Tailwind CSS 3](https://tailwindcss.com/)
- [GSAP](https://gsap.com/) for the intro animation

## Run it locally

Requires [Node.js](https://nodejs.org/).

```bash
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build in build/
```

## Editing content

All text, links, and images are in [`src/Details.js`](src/Details.js). The CV linked from the site is [`public/MoeYu_CV.pdf`](public/MoeYu_CV.pdf).
